# Customer Shopping Behavior Analysis

A comprehensive end-to-end data analytics project exploring customer shopping behavior using:
- Python (ETL & Analysis)
- SQL (Business Questions & DB insights)
- Power BI (Executive Visualization)

## 📋 Project Contents

### 📁 Data
`data/customer_shopping_behavior.csv` — core dataset used for analysis.

### 📊 Notebooks
Step-by-step Jupyter notebooks for:
- Data cleaning  
- Exploratory analysis  
- Feature engineering

### 🛠 Python Scripts
- **etl.py** – Loads and preprocesses the dataset  
- **load_to_sql.py** – Uploads cleaned data to SQL Server

### 🧠 SQL Queries
Stored under `sql/`: structured query files for answering business questions.

### 📈 Power BI Dashboard
Interactive visualization in `powerbi/Customer_Behaviour.pbix`.
