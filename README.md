## 🔍 Project Overview

This project analyzes customer shopping behavior using **Python, SQL Server, and Power BI**.  
The dashboard highlights key metrics such as customer count, purchase trends, ratings, and revenue distribution.

---

## 📌 Key Metrics

- **3.9K** Total Customers  
- **$59.76** Average Purchase Amount  
- **3.75** Average Review Rating  
- **27%** Customers with Subscription  

---

## 📈 Insights

- Revenue and sales by product category  
- Subscription vs non-subscription customer analysis  
- Sales and revenue by age group  
- Customer review behavior  

---

## 🛠 Tech Stack

- **Python** – Data Cleaning & Feature Engineering  
- **SQL Server (SSMS)** – Business Queries  
- **Power BI** – Interactive Dashboard
